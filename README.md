# MindEase

### Datasets

Clone the repos down below in your `models/datasets` folder.

- Go to the datasets folder
```shell

mkdir models/datasets
```
```shell
cd models/datasets
```

- Emotion Recognition Dataset
```shell

git clone https://huggingface.co/datasets/jobs-git/emotion-recognition-dataset
```

- Mental Health Condition Classification
```shell

git clone https://huggingface.co/datasets/sai1908/Mental_Health_Condition_Classification
```

- Student Mental Health Chat Data
```shell

git clone https://huggingface.co/datasets/chillies/student-mental-health-chat-data-v2
```

- Student Mental Health Conversation
```shell

git clone https://huggingface.co/datasets/chillies/student-mental-health-conversation
```

- Student Mental Health Counseling Vietnam
```shell

git clone https://huggingface.co/datasets/chillies/student-mental-health-counseling-vn
```
